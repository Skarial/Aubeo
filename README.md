# Aubeo

**L'éveil avant l'alarme**

Aubeo est une application mobile de réveil progressif.
Elle prépare progressivement l'éveil avant l'heure cible avec lumière, vibrations douces et ambiance sonore, au lieu de sortir brutalement du sommeil.

## Périmètre initial

- Base documentaire du projet
- Android d'abord
- iOS dans un second temps
- Séquence de réveil par phases : lumière -> vibrations douces -> ambiance sonore -> réveil final
- Logique adaptative simple, locale et explicable
