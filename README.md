# Aubeo

**L’éveil avant l’alarme**

Aubeo est une application mobile de réveil progressif. Elle prépare progressivement le réveil avant l’heure cible avec lumière, vibrations douces et ambiance sonore, puis déclenche un réveil final si nécessaire.

## Vision

Remplacer le choc d’une alarme brutale par une transition progressive, lisible et réglable.

## Objectif

Poser un cadre produit clair pour la v1 avant de démarrer le développement de l’application.

## Périmètre v1

- Android d’abord
- iOS plus tard
- séquence fixe : lumière -> vibrations douces -> ambiance sonore ou mode expérimental -> réveil final
- adaptation simple, légère et explicable
- aucune promesse médicale ni pseudo-scientifique

## Positionnement

- application de réveil progressive, sobre et crédible
- usage individuel centré sur une heure cible
- produit explicable, sans prétention d’analyse scientifique du sommeil

## Statut

- dépôt au stade de cadrage documentaire
- spécification produit et backlog MVP en cours de référence
